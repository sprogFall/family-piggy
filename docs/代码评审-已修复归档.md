## P0-1 编辑账单失败会清空整月列表(`aa1133f`,`v0.1.38`)

**原问题**:`transaction.store.update()` 先无条件删除本地快照,随后串行重拉各桶;`loadMonth` 的 catch 把桶写成 `{ status: 'error', transactions: [] }`。编辑保存后只要网络抖动,账单页就显示「本月暂无账单」,而 `error` 态没有任何页面消费。

**修复**:

- `update()` 不再先删本地快照,重拉成功才用服务端数据替换,失败保留旧数据并置 `error`。
- `loadMonth` / `loadPeriod` 失败保留旧 `transactions`,只改 `status`。
- 新增 `ErrorState` / `ErrorBanner`,账单 / 首页 / 统计 / 分类明细页消费 `error` 态并提供重试。

**位置**:`src/stores/transaction.store.ts`、`src/components/ErrorState.tsx`

## P0-2 `parseDateTimeCN` 静默接受非法日期并溢出到相邻月/年(`38377af`,`v0.1.38`)

**原问题**:正则只约束位数,`new Date(...)` 会静默进位。

| 输入 | 修复前解析结果 |
| --- | --- |
| `2026-13-01` | 2027-01-01 |
| `2026-02-30` | 2026-03-02 |
| `99:99` | 次日 |
| `0026-01-01` | 1926-01-01 |

**修复**:解析后逐字段回查(年 / 月 / 日 / 时 / 分与输入一致),不一致返回 `null`;同时修正自相矛盾的测试(`2024-13-01` 原本断言为「非 null」,与用例名「非法输入返回 null」冲突)。

**位置**:`src/domain/dates.ts`、`src/domain/dates.test.ts`

## 重构消除:家庭列表 `ledgers` 子查询忽略错误(`e879821` / `8e84333`)

**原问题**:`family.service.listMyFamilies()` 的 `ledgers` 子查询忽略 `error`,查询失败时家庭账本静默消失(`ledgerId: null`),且无提示。

**消除方式**:启动链路重构时改为 `listFamilies(userId)`(单次内嵌查询,只返回家庭);家庭账本 ID 改由 `ledger.store.load` 用 `listLedgers()` 的结果本地关联。`listLedgers()` 失败会抛错,不再出现「静默缺失」。

> 注:这是重构带来的结构性消失,并非专门补的错误处理。`family.service.ts` 其他子查询(`profiles`、`leaveFamily`)仍存在问题,见待修复文档。
